# 黄金矿工 · Gold Digger

使用 TypeScript、Phaser 3 和 Vite 实现的桌面浏览器游戏，支持单人五关旅程与同屏双人合作，包含高清矿区与角色、抓取与重量回收、商店、炸药、力量药水、计分、倒计时、暂停、结算、本地最高分及可选合成音效。

操作反馈包括矿工拉绳与绞盘动画、不同矿物的抓取粒子、入账反馈、目标进度条、达标和通关庆祝、最后 10 秒的颜色与声音提示。暂停时冻结动画；系统开启减少动态效果时会减少粒子和晃动。

## 运行

需要 Node.js 22.18+ 或 24+。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。单人模式用空格、下方向键或点击矿区出钩，B 或上方向键使用炸药。双人模式用同一副键盘，P1 用 S 出钩、W 炸药，P2 用下方向键出钩、上方向键炸药。P 暂停全场，页面切入后台自动暂停。以桌面键盘操作为设计目标，界面最小宽度 1080px。

页面顶部切换“单人旅程”与“双人合作”，点击开始或继续上次。切换模式会保存离开模式的检查点；两种模式的进度及最高纪录使用独立存储键。双人开采时点击矿区不会代替任何玩家出钩。

## 检查与发布构建

```sh
npm test
npm run build
```

`dist/` 为静态发布文件。开发服务器运行时执行 `node tools/smoke-test.mjs` 检查基本操作，执行 `node tools/campaign-test.mjs` 检查五关切换、商店与道具。测试通过开发环境接口推进状态和时间；并不等同于真人连续通关。默认寻找本机 Chrome 或 Edge；无本机浏览器时需先安装 Playwright Chromium。检查截图位于 `analysis/qa/`。

`node tools/save-test.mjs` 验证刷新恢复、道具保留、存储不可用、进度提示与动画；`node tools/balance-test.mjs` 用正常摆钩与回收逻辑模拟无道具开采，检查各关是否可达标。

`node tools/coop-test.mjs` 检查双键同时输入、独立钩子、矿物唯一归属、最后一块矿物仍在回收时的结算、炸药归属、共享商店、双方药水效果、五关合作通关，以及模式间存档隔离。平衡性模拟分别覆盖单人和双人五关，不替代真人难度评估。

## 原型规则与范围

- 五关分别为金色山谷、碎石坡地、水晶矿脉、深层金库、最后的宝藏，使用不同固定布局；目标依次为 $1,000 / $1,400 / $1,800 / $2,200 / $2,600，时限为 60 / 60 / 65 / 65 / 70 秒。
- 每关独立计算收益目标，达标后可继续收集，时间耗尽或矿物全部收回时结算。只有成功关卡的收益计入资金与总开采；购物扣资金，不影响目标或总开采纪录。
- 首关赠送 1 个炸药。商店炸药 $150，可跨关保留，上限 3 个；仅负重回收且未暂停时可使用，炸掉的物品不计收益。
- 双人合作目标为单人目标的 1.3 倍，即 $1,300 / $1,820 / $2,340 / $2,860 / $3,380；布局与时限相同。金色 P1、青色 P2 独立摆钩并显示本关贡献，双方收益相加达标。绳索可以交叉，一块矿物仅归一个钩子所有。
- 双人开局共 2 个炸药，共用背包上限仍为 3；各自炸药键仅摧毁自己钩子上的物品，并从共用数量扣除。资金和商店共用，一瓶力量药水对双方下一关同时生效。
- 力量药水 $300，每次商店限购 1 瓶，下一关自动生效，回收速度提升 65%，过关后失效。
- 失败可重试本关，恢复入关时资金、总开采、炸药和力量效果，失败收益不入账。重开整轮从第一关开始，重置资金和背包。
- 黄金价值分为 $50 / $250 / $500，钻石 $600，石头 $20。
- 本版时间、目标、矿物布局与回收公式均为原型配置，不代表已精确还原原版。
- 未接入原版 SWF 的美术和音效。
- 最高总开采纪录和闯关检查点保存在本机浏览器。刷新后点击“继续上次”恢复；关内从本关开头恢复，保留入关时的资金、道具与力量效果，不恢复中途分数和剩余秒数。商店余额和购买即时保存，恢复时不重复发放通关收益。整轮通关后清除续玩检查点，保留最高纪录。
- 重开整轮会覆盖旧检查点。损坏或不兼容的存档会被忽略；浏览器禁止写入时显示未保存提示，仍可正常游玩。
- 使用本机字体，不需要等待外部字体服务。

原版静态检查见 `analysis/原版分析.md`。游戏代码在 `src/main.ts`，关卡布局与道具价格在 `src/levels.ts`，碰撞与回收函数在 `src/mechanics.ts`，页面样式在 `src/style.css`。

存档验证与读写位于 `src/save.ts`，可清理的粒子效果位于 `src/feedback.ts`。

各玩家的钩子状态、碰撞抓取与矿工动画位于 `src/player.ts`；团队计时、计分、商店与结算由主场景统一管理。

## 高清素材

`public/assets/` 收录用户提供的 `gold_miner_assets.zip` 中全部 25 张原始 PNG，约 9 MB。五张背景分别对应五关，两名矿工使用待机、回收与庆祝三张静态姿势图，配合程序微动；矿物、抓钩、工作台、旋转手轮、商店道具、金币、闪光和爆炸均已接入。绳索、文字和界面继续由程序绘制。

`src/assets.ts` 管理预加载和图片帧。根据 Alpha 实际轮廓在运行时选取透明留白内的有效区域，让矿物图像匹配现有碰撞尺寸，未改写原始 PNG；背景分为天空和地下两段映射到地面高度，玩法坐标、分数与存档规则不变。

`node tools/inspect-assets.mjs` 生成尺寸、Alpha 和边界报告及素材总览；`node tools/assets-test.mjs` 验证 25 张纹理、五关背景切换、双人动作和商店图标，截图在 `analysis/qa/hd-*.png`。浏览器测试等待预加载完成后开始操作。
