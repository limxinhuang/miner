# 黄金矿工 · 合作远征

TypeScript + Phaser 3 + Vite 实现的桌面浏览器同屏双人游戏。当前仅保留肉鸽远征：随机选路、共用钱包、站间补给、个人福袋和失败结束本轮。

## 启动

需要 Node.js 22.18+ 或 24+。在另一台电脑上复制项目（无需 node_modules），进入项目目录运行：

```sh
npm ci
npm run dev
```

用桌面 Chrome 或 Edge 打开终端显示的地址。不要直接双击 index.html。生产构建运行 `npm run build`，将生成的 dist 目录交给静态网站服务器。

## 玩法

- 每轮 5 站，每站提供 3 条路线，两位玩家分别点击自己的选路按钮，选中同一条后出发。路线种类包括富金、水晶、遗迹和危险矿洞；路线组合和矿物位置由本轮随机种子生成。
- 只有一个共用钱包。矿物送达后立即入账；矿区结束时检查钱包余额是否达标。商店消费会增加下一站的资金缺口，不撤销上一站通关，也不重复发放采矿收入。
- 基础余额目标依次为 $1,200 / $2,500 / $3,900 / $5,400 / $7,200；水晶路线额外要求 $150，危险路线额外要求 $250。各路线有独立时限。
- 每个普通矿区有 2 个福袋，遗迹矿区有 4 个。单人钩取并完整拉回后，立即按收集者运气打开并入账，不暂停游戏，基础 $300，中等奖励 $500，大奖 $800。未送达或炸毁的福袋没有奖励。
- 开局共用 2 个炸药。商店炸药 $150，背包上限 3 个，只能炸掉自己钩子上的普通矿物；力量药水 $300，下一站双方负重及空钩回收加速 65%，每次休整限购一瓶。
- 时间耗尽，或全部物品回收完成时结算；直接检查当前钱包目标，不再追加奖励。失败清空本轮钱包、道具和续玩存档，重新开始会生成新一轮；没有重试当前矿区。通关保留最高最终钱包纪录。
- 当前是肉鸽基础循环，尚未加入遗物构筑、事件节点或福袋道具掉落。

## 操作与测试设置

P1：S 出钩 / 松钩，W 炸药。P2：下方向键出钩 / 松钩，上方向键炸药。P 暂停全场。页面切入后台自动暂停。仅面向桌面键盘，界面最小宽度 1080px。

页面保留“手感调节”供测试：摆动与拉取倍率均为 0.10–5.00，默认 1.00，双方共用且即时生效。摆动基准角速度为 1.15 弧度/秒；普通回收速度为 `390 / (1 + 重量 × 0.48)`，再乘个人力量倍率，并乘拉取倍率与药水倍率。出钩速度为 440 逻辑像素/秒。设置独立保存在浏览器，可复制参数或恢复默认。

## 存档

当前远征自动保存在本机浏览器，记录钱包、路线种子、剩余时间、矿物消耗、钩子位置及负重、经验和属性点。刷新后点击“继续远征”，采矿现场以暂停状态恢复，再按 P 继续。购物和选路也会保存；不会通过刷新补充时间或重生矿物。新开远征覆盖当前进度。

远征使用新的存档键，不读取旧传统模式存档。损坏的存档会被忽略；浏览器禁止保存时页面会提示。存档和测试参数不会随项目文件自动迁移到另一台电脑。

## 代码与素材

- src/main.ts：远征、共用钱包、选路、补给、结算及页面状态。
- src/expedition.ts：随机路线、矿物布局、目标和道具价格。
- src/growth.ts：经验等级、属性点、力量倍率和确定性福袋奖励。
- src/player.ts、src/mechanics.ts：各玩家钩子、碰撞、重量回收和动作。
- src/save.ts：存档校验与读写；src/tuning.ts：测试参数。
- src/assets.ts、src/feedback.ts：高清图片、动画帧和反馈效果。

public/assets 保留用户提供的全部 25 张原始 PNG。背景、双人矿工姿势、普通矿物、钩子、工作台、商店图标和粒子已接入；福袋、绳索与界面由程序绘制。未接入原版 SWF 的美术和音效。原版分析保留在 analysis/原版分析.md。

## 个人成长与结算

普通矿物每入账 $1，收集者获得 1 经验。钱包共用、经验独立；购买补给不扣经验。1 级升 2 级需 500 经验，之后每级需求增加 250；每升一级获得 1 点，仅在通关后的营地分配。未花点数可保留，重开远征或失败重置成长。

力量每点对重量 8 及以上的物品增加 12% 回收速度，较轻物品按重量比例生效，空钩不受属性影响；与测试倍率、药水相乘。运气每点提高大奖概率 2 个百分点、中等奖或更高概率 5 个百分点；两者分别封顶 25% 和 75%。初始大奖概率 5%、中等奖概率 25%、保底概率 70%。

福袋完整拉回后，按收集者当前运气确定奖励，立即增加共用钱包、个人本局收入和经验。钩子旁显示短暂“福袋 +$金额”飘字；升级提示新增点数，仍在营地加点。结算只展示最终钱包与目标、双方本局收入和等级变化；福袋收益包含在本局收入中，不再单列或重复发放。相同种子、站点和福袋编号对应同一次抽取，刷新不会重抽或重复入账。旧 v2 存档中的待开福袋在恢复时入账一次，已结算的奖励不会再次发放。

成长版本使用 gold-digger-expedition-v2 存档，旧宝箱版本存档不迁移。测试参数仍使用原来的独立存储。

## 游戏内界面

界面采用固定比例的游戏窗口：顶部钱包、目标和计时器，底部双方等级、属性和键位提示。采矿结束后展示简洁结算，再进入营地；营地通过“成长与补给 / 选择路线”页签切换，无需在长页面间滚动。手感调节收在窗口下方的可折叠测试面板。

`src/game-ui.ts` 整理游戏内界面节点，`src/game-ui.css` 管理布局及结算动画。`node tools/ui-test.mjs` 检查桌面窗口下各阶段均无页面或面板纵向溢出，并输出 analysis/qa/ui-*.png。开启减少动态效果时禁用结算动画。原有 v2 远征存档继续兼容。

## 高清 UI 素材

已接入 gold_miner_ui_assets.zip 中全部 27 张 PNG，原始图片保留于 public/assets/ui。木质外框、仪表底板、双人状态牌、按钮、页签、标题横幅、成长和商店卡片由 src/ui-art.css 渲染；面板和按钮使用固定角部切片缩放，文字仍由程序显示。路线插画对应四种矿区，经验条按玩家使用金色或青绿色，达标与失败使用对应徽章。场上福袋按实际透明轮廓取帧，抓取规则不变。

node tools/inspect-ui.mjs 可重新生成 analysis/ui-assets.json（尺寸、Alpha 与轮廓边界）和 analysis/ui-contact.png（素材总览）。游戏内 UI 测试覆盖常见桌面尺寸，原有成长、即时开袋和存档流程测试继续适用。
